## ✨ Features & Highlights

- **✨ Ambient Stardust & Rose Petals**: Floating golden dust and gentle rose petals drifting over an obsidian and velvet wine palette.
- **🎵 Zero-Dependency Romantic Audio Synthesizer**: Built-in Web Audio API acoustic music box and harp arpeggios (`Play Our Melody`) with chord chime interactions.
- **⏳ Live Wedding Countdown**: Real-time ticker counting down days, hours, minutes, and seconds to the big day.
- **📜 The Sacred Letter & Wax Seal**: Heartfelt vows paired with an interactive monogram wax seal (`H&A`) that responds with gentle chimes and floating hearts upon touch.
- **📖 Our Story Timeline**: Interactive milestones tracing the journey from the first conversation to eternity.
- **📷 Interactive Photo Vault & Lightbox**: Memory frames with custom artwork, fullscreen modal viewing, and in-browser photo uploading (stored locally in `localStorage`).
- **💌 Archana's Private Vault**: An interactive response note box where Archana can write and preserve her thoughts forever.
- **🎉 Interactive Proposal Finale**: Grand celebration with sparkling floating hearts, dynamic feedback, and romantic melodies.

## 🚀 Live Preview & Deployment (GitHub Pages)

This project is 100% self-contained standard HTML5, CSS3, and modern Vanilla JavaScript with no build steps or dependencies.

### Enabling GitHub Pages:
1. Go to your repository **Settings** on GitHub: `https://github.com/Hemsagar00/hemsagar_archana_forever/settings/pages`
2. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
3. Under **Branch**, select `main` (or `master`) and `/ (root)`, then click **Save**.
4. Within a minute, your website will be live at:
   ```
   https://hemsagar00.github.io/hemsagar_archana_forever/
   ```
